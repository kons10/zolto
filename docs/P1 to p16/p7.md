# Zolto Phase 7 — Native Vector Graphics & Drawing Engine

## Goal

Build a modern vector graphics engine integrated directly into Zolto.

The engine should provide a declarative, human-readable drawing language capable of producing high-quality scalable graphics without requiring SVG or external tools.

Everything from Phases 1–6 must continue working.

---

# Objectives

Develop a complete vector graphics subsystem featuring:

* Native drawing language
* Scene graph
* Shape system
* Styling engine
* Transform system
* SVG renderer
* Export support
* Accessibility
* High performance

---

@/vector

## Not Included

Do NOT implement

* Spatial layout engine
* Component system
* Templates
* Plugin API
* Presentation engine
* Interactive editor

These belong to later phases.

---

# Final Goal

At the end of Phase 7, Zolto should provide a complete native vector graphics language capable of producing scalable illustrations, UI diagrams, scientific figures, and technical drawings while integrating seamlessly with the existing Markdown, Math, Diagram, and Chart systems.

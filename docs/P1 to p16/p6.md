# Zolto Phase 6 — Native Charts & Data Visualization Engine

## Goal

Build a high-performance native chart engine that transforms structured data into beautiful, interactive, and accessible visualizations directly inside `.zl` documents.

The engine must be independent from the diagram engine while sharing the common AST, rendering pipeline, and theme system.

Everything from Phases 1–5 must continue working without breaking compatibility.

---

# Objectives

Create a complete data visualization system featuring:

* Native chart syntax
* Data parser
* Statistical utilities
* Multiple chart types
* SVG renderer
* Animation-ready architecture
* Accessibility
* Export support
* High performance

---

# 1. Chart Directive

  Mar
  Apr

## Project Structure

* tokenizer
* parser
* ast
* datasets
* statistics
* renderer
* svg
* validator
* diagnostics
* themes
* tests
* examples
* docs

Maximum source file size: 800 lines.

Every module should have a single responsibility.

---

## Not Included

Do NOT implement

* Native vector editor
* Spatial layouts
* Component system
* Templates
* Plugin system
* Interactive dashboards
* Presentation mode

These belong to future phases.

---

# Final Goal

At the end of Phase 6, Zolto should include a production-ready chart engine capable of transforming structured data into elegant, accessible, high-performance visualizations while integrating naturally with the rest of the Zolto language.

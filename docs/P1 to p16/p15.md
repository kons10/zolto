# Zolto Phase 15 — Universal Theme & Design System

## Goal

Build a complete theme system for Zolto so every document, presentation, dashboard, component, chart, diagram, and interactive block can adapt visually in a consistent, accessible, and branded way.

This phase adds the visual identity layer of Zolto.

Everything from Phases 1–14 must continue working exactly as before.

---

# Objectives

Create a universal theming engine featuring:

* Light theme
* Dark theme
* Eye Protection mode
* Theme tokens
* Color systems
* Typography systems
* Spacing systems
* Radius systems
* Shadows
* Motion tokens
* Icon theming
* Component styling
* Theme switching
* Theme inheritance
* Theme packaging
* Accessibility support
* Export consistency

---

# 1. Core Themes

Implement at least these built-in themes:

## Light Theme

A clean, bright, readable theme for normal daytime use.

Requirements:

* high readability
* soft surfaces
* clear hierarchy
* low visual noise
* good print compatibility
* professional document appearance

## Dark Theme

A modern dark theme for low-light environments.

Requirements:

* reduced glare
* strong contrast
* comfortable long-session reading
* good code and diagram visibility
* balanced accent colors

## Eye Protection Mode

A dedicated low-strain theme for long reading and night use.

Requirements:

* warm background tones
* reduced blue light feel
* softer contrast than dark theme
* easy on the eyes for extended use
* comfortable for text-heavy documents
* accessible without becoming washed out

Eye Protection mode must not be just a slightly tinted dark theme. It should be a distinct theme with its own color logic and readability rules.

# 7. Accessibility Rules

Theme engine must support accessibility-first rendering.

Support:

* WCAG-aware contrast
* reduced motion compatibility
* high visibility focus states
* large text mode
* dyslexia-friendly variations
* color-blind-safe palettes
* eye protection defaults for long reading

Eye Protection mode should prioritize comfort without destroying clarity.

* smooth transitions
* renderer updates safely
* fallback to default theme if missing

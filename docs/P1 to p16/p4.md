# Zolto Phase 4 — Native Mathematics Engine

## Goal

Build a complete mathematics engine that rivals LaTeX while remaining significantly easier to write and read. The engine must integrate seamlessly with the existing Markdown foundation developed in previous phases.

Everything from Phases 1–3 must continue working without breaking compatibility.

---

# Objectives

Create a production-quality mathematical language featuring:

* Inline mathematics
* Display mathematics
* Equation numbering
* Cross references
* Mathematical AST
* High-performance parser
* Multiple rendering backends
* Accessibility
* Fast incremental rendering

---

# 1. Inline Math

Implement

```zolto
$E = mc^2$

$a+b=c$

$\frac{a}{b}$

$\sqrt{x}$

$\sum_{i=1}^{n}x_i$
```

Requirements

* Nested expressions
* Escaped dollar support
* Currency detection
* Smart delimiter matching
* Error recovery
* Unicode support

---

# 2. Display Math

# 3. Equation References

Implement

```zolto
@math label="eq:newton"

@/math

See @ref(eq:newton)
```

Requirements

* Automatic numbering
* Hyperlinks
* Duplicate detection
* Missing reference diagnostics

## Not Included

Do NOT implement

* Diagrams
* Charts
* Vector graphics
* Components
* Layout engine
* Animation
* Plugin system
* Interactive widgets

These belong to later phases.

---

# Final Goal

At the end of Phase 4, Zolto should provide a modern, fast, accessible, and extensible mathematics engine that is compatible with LaTeX concepts while being simpler to write and deeply integrated with the Zolto document model.

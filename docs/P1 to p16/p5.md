# Zolto Phase 5 — Native Diagram & Graph Engine

## Goal

Build a high-performance native diagram engine capable of creating professional diagrams directly inside `.zl` documents.

The engine must be human-readable, deterministic, extensible, and deeply integrated with the Zolto AST.

Everything from Phases 1–4 must continue working.

---

# Objectives

Develop a complete diagram subsystem with:

* Native diagram syntax
* Graph parser
* Layout engine
* SVG renderer
* Themes
* Animations (structure only)
* Cross references
* Accessibility
* Incremental rendering

---

# 1. Diagram Directive

Implement

```zolto
@diagram flowchart

Start -> Login
Login -> Dashboard
Dashboard -> Settings

@/diagram
```

Support nested directives and attributes.

---

## Not Included

Do NOT implement

* Charts
* Native vector editor
* Freehand drawing
* Spatial layout engine
* Components
* Templates
* Plugin system
* Interactive editing

These belong to later phases.

---

# Final Goal

At the end of Phase 5, Zolto should include a production-ready native diagram engine capable of generating beautiful, accessible, scalable SVG diagrams directly from `.zl` documents, providing a strong alternative to Mermaid while fitting naturally into the Zolto language.

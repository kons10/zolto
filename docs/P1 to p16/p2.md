You are continuing development of Zolto.

Phase 2 Goal:
Transform the Markdown engine from Phase 1 into a polished, production-quality document language while remaining 100% compatible with standard Markdown. This phase focuses on extending Markdown itself—not introducing advanced domains like math, diagrams, layouts, or components.

Everything from Phase 1 must continue working exactly as before.

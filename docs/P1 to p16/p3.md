You are continuing development of Zolto.

Phase 3 Goal

Transform Zolto from an extended Markdown language into a modern rich document language.

This phase introduces Zolto-native block elements while keeping every Markdown document fully compatible.

No mathematics, diagrams, charts, components, layouts, or graphics yet.

Everything from Phase 1 and Phase 2 must continue working.

# Zolto Spatial Layout & Canvas Engine Guide

**Version:** 8.0.0 · Phase 8 · Spatial Layout Engine

---

## Overview

Zolto Phase 8 introduces a powerful, declarative **Spatial Layout & Canvas Engine** for creating responsive dashboards, multi-column reports, posters, multi-page print documents, slide presentations, and interactive application interfaces inside `.zl` documents with zero external dependencies.

Layout containers work seamlessly with all previous Zolto domains (Markdown, Math, Diagrams, Charts, and Vector Graphics).

---

## 1. Top-Level Layout (`@layout`)

```zolto
@layout width=1200 padding=24 gap=16 theme="dark"
  @header
    # Annual Report 2026
  @/header

  @main
    Main content goes here...
  @/main

  @footer
    Generated by Zolto Engine
  @/footer
@/layout
```

### Attributes
| Attribute | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `width` | number \| string | `'auto'` | Width in px, `%`, `'auto'`, `'fill'`, `'page'` |
| `height` | number \| string | `'auto'` | Height in px, `%`, `'auto'`, `'fill'` |
| `padding` | number \| string | `24` | Inner padding in px or CSS spacing |
| `margin` | number \| string | `0` | Outer margin in px or CSS margin |
| `gap` | number \| string | `16` | Gap between header, main, and footer blocks |
| `theme` | string | `'default'` | Theme name (`'default'`, `'dark'`, `'light'`, etc.) |
| `responsive` | boolean | `true` | Enables automatic layout adaptation |

## 2. Grid Layout (`@grid` & `@cell`)

```zolto
@grid columns=12 gap=20
  @cell span=4
    Left Panel
  @/cell

  @cell span=8
    Main Content
  @/cell
@/grid
```

### Named Areas

```zolto
@grid columns=3 areas="header header header\nsidebar main main\nfooter footer footer" gap=16
  @cell area="header"
    Top Bar
  @/cell
  @cell area="sidebar"
    Navigation
  @/cell
  @cell area="main"
    Dashboard Cards
  @/cell
@/grid
```

### Grid Attributes
- `@grid`: `columns`, `rows`, `gap`, `row-gap`, `column-gap`, `auto-fit`, `auto-fill`, `min-cell-width`, `align`, `justify`, `areas`
- `@cell`: `span`, `row-span`, `area`, `align`

---

## 3. Flexbox Layout (`@flex` & `@item`)

```zolto
@flex direction="row" justify="space-between" align="center" gap=16
  @item grow=1
    Flexible Left Item
  @/item

  @item basis=240
    Fixed Width Item
  @/item
@/flex
```

### Flex Attributes
- `@flex`: `direction` (`'row'` \| `'column'`), `wrap` (`true` \| `false`), `justify` (`'start'` \| `'center'` \| `'end'` \| `'space-between'`), `align` (`'start'` \| `'center'` \| `'end'` \| `'stretch'`), `gap`
- `@item`: `grow`, `shrink`, `basis`, `align-self`

## 4. Stack Layout (`@stack`)

```zolto
@stack mode="overlay"
  @item z=1
    Base Content Block
  @/item
  @item z=2
    Floating Badge
  @/item
@/stack
```

## 5. Canvas & Absolute Positioning (`@canvas`)

```zolto
@canvas width=1920 height=1080 snap=8 guides=true
  @layer id="background" z=0
    @rect x=0 y=0 w=1920 h=1080 fill="#0f1117"
    @/rect
  @/layer

  @layer id="title" z=10
    @text x=120 y=120 size=64 weight=700
      Zolto Spatial Engine
    @/text
  @/layer
@/canvas
```

## 6. Multi-Page & Print Layout (`@pages` & `@page`)

```zolto
@pages size="A4" margin=32 bleed=0
  @page number=1
    # Page 1 Title
    Content...
  @/page

  @page break=always
    # Page 2 Title
    Content...
  @/page
@/pages
```

## 7. Slide Presentation Deck (`@presentation` & `@slide`)

```zolto
    ### Spatial Layout & Presentation Runtime
  @/slide

  @slide type="content"

    - Grid & Flex Systems
    - Print & Slide Decks
  @/slide
@/presentation
```

## JavaScript API

```javascript
import { parseLayout, renderLayout, validateLayout } from './src/layout/index.js';

const source = `@grid columns=2 gap=16
@cell
Cell 1
@/cell
@cell
Cell 2
@/cell
@/grid`;

const { ast, diagnostics } = parseLayout(source);
const html = renderLayout(ast);
```
